# Indicators

TradingView indicators written in Pine Script v6. Each folder holds the script and its documentation.

| Indicator | What it does |
|---|---|
| [Fractal Alignment](fractal-alignment/) | Fractal Model setups (C2 sweep / reclaim, CISD, T-Spot, protected swings, SMT, PSP) with the higher-timeframe candles to the right of price, plus two optional extra HTF blocks. |
| [Fractal Reclaim Strength](fractal-reclaim-strength/) | The latest C2 sweep / reclaim setup on the chart timeframe and historical C3 / C4 survival rates grouped by reclaim strength. |

To use one, paste its `.pine` file into the TradingView Pine Editor, save, and add it to a chart.
